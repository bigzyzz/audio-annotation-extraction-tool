# packages/shared-types

Shared TypeScript types used by both `apps/web` and `apps/worker`.

- `src/database.types.ts` — generated by `supabase gen types typescript`, matches the live schema in `supabase/migrations/`. Never hand-edit; regenerate with `pnpm --filter @audio-tool/shared-types gen-types` after every migration (needs `SUPABASE_ACCESS_TOKEN` set — see supabase.com/dashboard/account/tokens).
- `src/index.ts` — convenience row-type aliases (`Profile`, `AudioFile`, `Annotation`, `ExtractionJob`, plus their `Insert`/`Update` variants) re-exported from the generated `Database` type.
